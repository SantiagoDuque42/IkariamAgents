# IkariamAgents

An information system for Ikariam: extractors that read the game (only when you click them), a shared data store in Google Drive, importers that write the data into the alliance's sheets, and a Strategist (a Claude session) that turns it all into plans you carry out by hand.

```
 game tab ──bookmarklets──▶ Drive "Agentic Development/inbox" ──▶ importer ──▶ sheets (Farmeos, …)
                                         │                                   
                                         └──▶ data/<subsystem>/ ──▶ Strategist (Claude) ──▶ orders (click list) ──▶ you
```

| Subsystem | What it does | Output schema | Status |
|---|---|---|---|
| **Mayor** | Your towns: buildings, population, stock, wine, production, units, island levels | `mayor.snapshot.v1` | v0.2: island read fixed (untested in game) |
| **Cartographer** (game source) | Islands in an area, with filters: good, levels, wonder, free spots, towns, players | `cartographer.map.v1` | v0.1: first real run will confirm response shapes |
| **Cartographer** (ikadatos) | Islands, towns, players and inactives from ikadatos, run on the ikadatos page in your browser | `cartographer.map.v1` | v0.1 (the site refuses server-side requests) |
| **Spymaster** | Spy reports from your Hideouts + target warehouse/wall/inactive → Farmeos | `spymaster.reports.v1` | v0.1 |
| **Strategist** | Reads the store + doctrine, simulates, emits orders | `strategist.orders.v1` | engine in `strategist/engine`, protocol in `strategist/PROTOCOL.md` |
| **Basileus** | Executes approved orders in your Chrome (Claude in Chrome): builds, transports, workers/wine | `basileus.journal.v1` | B0: contract, policy, playbook; see `docs/BASILEUS.md` |
| Planned exporters | Military history, transports, … (each to its own spreadsheet) | one schema each | see "Adding an exporter" |

## Rules

1. **Extractors only read**, only when you click them, at a human pace. **Basileus** is the only part that acts in the game, only on steps you approved, within its policy. Gameforge's rules forbid bots, so using Basileus is a risk you take for your own account (see `docs/BASILEUS.md`).
2. **The contract is the system.** Every file is an envelope (`schemas/envelope.v1.json`) with a versioned schema. Consumers read files, never each other's internals.
3. **This repo is public: no real game data in it.** Snapshots, reports, doctrine and plans live in the private Drive folder. Fixtures here are anonymised.

## Use

1. **Install a bookmarklet:** copy the contents of `dist/<tool>.bookmarklet.txt` and paste it as the URL of a new bookmark.
2. **Choose where downloads land:** set the browser you play in to download into the Drive-synced folder `IKARIAM [ATLAS]/Agentic Development/inbox` (or move the files there).
3. **Import into the sheets:** install `sheets/AtlasImporter.gs` in the spreadsheet (see `sheets/README.md`). Then use the menu **ATLAS → Import now**, or turn on automatic import every 15 min.
4. **Plan:** ask the Strategist (Claude, in the Ikariam project) for a plan. It reads the newest files.

## Develop

```
npm test                 # unit tests (node:test) + schema validation of fixtures (python jsonschema)
npm run build            # dist/*.js and dist/*.bookmarklet.txt from the sources + shared/ikariam.js
python3 tools/validate.py <file.json>   # validate any store file
```

`strategist/engine/costs.js` is generated by `tools/gen-costs.mjs` from IkaEasy's in-game Help scrape. It is identical to the table the planner used.

### Adding an exporter (military history, transports, …)

1. `schemas/<subsystem>.<kind>.v1.json`: `allOf` the envelope, define `payload`.
2. `<subsystem>/<subsystem>.bookmarklet.js`:
   - start with `/*@shared*/`
   - read with `gameClient().get`, pace requests with `pace()`
   - save unknown shapes with `shape()` into `diag`
   - finish with `download(envelope(...), name)`
3. Add the bookmarklet to `targets` in `tools/build.mjs`.
4. Add an anonymised fixture and a test.
5. Importer: add `'<schema>': importX_` to `HANDLERS` in `sheets/AtlasImporter.gs`. Keep the row-building logic in pure functions so `tests/importer.test.mjs` can test them.

See `docs/ARCHITECTURE.md` for the design.

# Ejército terrestre y función de cada unidad

Revisión: 2026-11-20

| Papel | Unidades de referencia |
|---|---|
| Primera línea pesada | Hoplitas, gigantes a vapor; espartanos especiales |
| Infantería ligera / flancos | Lanceros y espadachines |
| Combate a distancia | Honderos, arqueros y fusileros de azufre |
| Artillería | Arietes, catapultas y morteros |
| Defensa aérea | Girocópteros |
| Bombardeo | Globos bombarderos |
| Apoyo | Cocineros y médicos |

La eficacia depende de casillas del campo, tamaño de unidad, munición, equipamiento, rival y reservas. La muralla añade una barrera que exige capacidad adecuada de asedio. Ganar no depende solo del número total de unidades.

Las batallas se desarrollan por rondas. Hay que mantener frente, moral y suministros; munición agotada y pérdidas pueden cambiar qué líneas combaten. El apoyo no sustituye las unidades que ocupan las casillas. Evitar la receta antigua de un número fijo de cocineros para cualquier batalla.

Método propio: pedir informe completo, tamaño de campo, unidades por bando, mejoras de taller, milagros y refuerzos. Calcular mantenimiento y reposición junto al plan de combate. Cuando faltan datos, dar escenarios y una lista concreta de lo que cambia el resultado; no presentar una victoria garantizada ni un simulador exacto basado en estadísticas antiguas.

# Catálogo funcional de edificios

Revisión: 2026-11-20

| Función | Edificios |
|---|---|
| Gobierno y expansión | Ayuntamiento, palacio, residencia del gobernador |
| Ciencia y equipamiento | Academia y taller |
| Población | Taberna y museo |
| Almacenamiento | Almacén y depósito |
| Comercio y carga | Puerto comercial y tienda |
| Ejército y armada | Cuartel, astillero de guerra, muralla, mercado negro |
| Información y alianzas | Escondite y embajada |
| Religión | Templo y santuario de los dioses |
| Navegación | Archivo de cartas náuticas y depósito de mercantes / Dockyard |
| Actividades especiales | Fortaleza pirata, teatro, torre de Helios, fuente de ambrosía |
| Velocidad de construcción | Forja de Cronos |

Los productores y reductores tienen un módulo económico propio. Los nombres traducidos pueden variar: conservar también el nombre inglés si la interfaz genera ambigüedad.

El almacén aporta capacidad y protección frente al saqueo. El depósito permite almacenar, pero no añade la misma protección. Capacidad total, cantidad protegida y materiales disponibles son variables diferentes. El taller mejora equipamiento; no confundirlo con la investigación de la academia.

Para presupuestar una mejora registrar ciudad, nivel actual y objetivo, coste que muestra el juego, duración, reductores, Cronos, gobierno y bonificaciones. Las tablas de versiones antiguas pueden ser incompatibles. Un edificio puede seguir aumentando puntuación después de alcanzar el límite de su efecto: comprobar utilidad marginal.

No recomendar demoler o trasladar una ciudad a partir de una imagen parcial. Primero inventariar huecos, funciones imprescindibles y consecuencias para el resto del imperio.

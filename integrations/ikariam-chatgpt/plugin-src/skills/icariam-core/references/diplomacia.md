# Espionaje, alianzas y tratados

Revisión: 2026-11-20

El escondite permite disponer de espías; mantenerlos en casa contribuye a la defensa frente al espionaje. Las misiones tienen riesgo, que debe leerse antes de realizarlas. El nivel de ciudad, el escondite y el número de agentes intervienen. Un informe de espionaje es una observación de un momento, no una visión permanente.

Las alianzas se gestionan mediante embajada y puntos diplomáticos. Permiten cooperación y apoyo; una alianza cercana puede resultar más útil que otra muy alta en clasificación pero sin presencia local. Cargos habituales: líder, ministro del interior, general y diplomático, con responsabilidades diferentes.

Los tratados culturales alimentan el museo; los acuerdos de guarnición, paz o comercio tienen efectos distintos. No inferir permisos militares a partir de un tratado cultural. Antes de recomendar atacar, comprobar acuerdos aplicables y datos actuales.

Plan propio: guardar contactos y acuerdos solo cuando sean relevantes para la cuenta; anotar vigencia, partes y fuente. Preparar mensajes claros con coordenadas, horas y necesidades; no enviarlos sin instrucción del usuario. Para coordinar refuerzos usar la misma referencia horaria y diferenciar salida, llegada y disponibilidad para nueva misión.

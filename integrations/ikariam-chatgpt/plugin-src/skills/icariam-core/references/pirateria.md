# Piratería y pueblo bárbaro

Revisión: 2026-11-20

La fortaleza pirata habilita el sistema de rapiña. Las misiones generan puntos de captura y se puede fortalecer la tripulación. También existen incursiones contra fortalezas ajenas. Puntos, tripulación y clasificación son variables distintas; dedicar puntos a fuerza puede cambiar el balance entre premio y defensa.

Los ciclos tienen cierre y premios. Para planificar uno concreto hay que observar fecha de finalización, fuerza efectiva, puntos, rango de posibles objetivos y reglas vigentes de recompensa. No asumir que un premio antiguo o una clasificación previa siguen siendo válidos.

El pueblo bárbaro es un objetivo PvE con niveles y defensas progresivas. Las guías separan grupos de niveles y describen escalada de dificultad. Registrar el nivel observado y el informe de la última batalla; no recomendar el mismo ejército para todos los pueblos.

Análisis propio: botín esperado menos coste de bajas, mantenimiento y ocupación de barcos. Comparar también el tiempo de atención que exige la actividad con la disponibilidad del usuario. Conservar evidencias del resultado, no marcar una misión planificada como completada por el mero paso del tiempo.

Icariam permite preparar decisiones y llevar el registro de estas actividades a partir de datos aportados; no ejecuta ciclos repetitivos dentro del juego.

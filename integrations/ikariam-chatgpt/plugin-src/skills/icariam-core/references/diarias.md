# Tareas, favor, prémium y eventos

Revisión: 2026-11-20

Las tareas diarias entregan favor canjeable por materiales, oro, investigación, unidades, efectos prémium y bendiciones, dependiendo de condiciones y catálogo. Los requisitos y cantidades pueden variar con el desarrollo de la cuenta. Leer el ciclo y las recompensas actuales; no fijar para todos los servidores una hora de reinicio tomada de una guía antigua.

La versión 17.3.0 cambió al 10% la bonificación de producción del teatro. Por ello, una página que aún indique otro porcentaje no basta para calcular producción actual. La 17.4.0 añadió una recompensa diaria de aumento de ingresos de oro. La 17.5.0 exige veneración activa para ciertos canjes de bendiciones.

La ambrosía financia opciones prémium. Evaluar precio y efecto en la interfaz antes de recomendar una compra. Método propio: comparar el ahorro real con opciones gratuitas y con el presupuesto expresado por el usuario; no asumir que quiere gastar por buscar una estrategia eficiente.

En eventos temporales, verificar anuncio, comunidad, fecha y reglas del evento. Abyssal Ambush y otras actividades tienen sus propios sistemas: la mera existencia de una corrección no demuestra que el evento esté activo hoy. Las recompensas pendientes solo se consideran recogidas cuando el usuario o una evidencia lo confirman.
